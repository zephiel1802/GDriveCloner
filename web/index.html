🤖 Script tự động xóa (Apps Script)

Để thư mục tự xóa kể cả khi app đóng:

  1. Mở script.google.com → Tạo project mới
  2. Copy nội dung file AutoDelete.gs vào editor
  3. Bấm Run một lần để cấp quyền
  4. Vào Triggers (⏱) → Add Trigger:
      • Function: autoDeleteExpiredFolders
      • Event: Time-driven → Hour timer → Every hour
  5. Deploy xong là app tự xóa mỗi giờ!
